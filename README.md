# MyContactList (iOS)

MyContactList is an iOS contact management application built with Swift. The app allows users to store, manage, and interact with contact information directly from their mobile device. It demonstrates core mobile development concepts, including data persistence, user interface design, and device feature integration.

## Features

- Create and manage contact entries
- Store contact information locally using Core Data
- Quick-call functionality directly from the app
- SMS messaging integration
- Location support using Google Maps
- Image capture for contact photos
- Battery monitoring display
- Segmented tab interface for intuitive navigation

## Tech Stack

- Swift
- UIKit
- Core Data
- Xcode
- Google Maps API

## Purpose

The purpose of this project was to develop a functional mobile contact management system while practicing iOS development concepts such as local data storage, UI design, and device feature integration.
